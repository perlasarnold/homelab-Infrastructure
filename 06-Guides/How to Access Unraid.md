# How to Access Unraid

**Difficulty:** 🟢 Beginner  
**Time:** ~2 minutes

---

## What you need

- A device on the same network (192.168.1.x)
- A modern web browser
- Your Unraid login credentials

---

## Steps

### 1. Open the Web Interface

Open your browser and go to:

```
https://192.168.1.24
```

> ⚠️ **Certificate Warning**: You may see a certificate warning. Click **Advanced → Accept the Risk and Continue** (Firefox) or **Advanced → Proceed** (Chrome) to bypass it.

### 2. Log In

| Field | Value |
|-------|-------|
| **Username** | `root` (or your username) |
| **Password** | Your Unraid password |

Click **Login**.

### 3. You're In!

You'll land on the Unraid dashboard.

---

## Unraid Dashboard Layout

| Tab | What's There |
|-----|-------------|
| **Dashboard** | System health, array status, usage |
| **Main** | Array drives, cache, parity status |
| **Shares** | Network shares (SMB/NFS) |
| **Users** | User management |
| **Plugins** | Installed plugins |
| **Docker** | Running containers |
| **VMs** | Virtual machines |
| **Settings** | Server configuration |
| **Apps** | Community Applications marketplace |
